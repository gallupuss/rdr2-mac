# Changelog

## 0.1.0 — experimental source release

- Native SwiftUI setup and session controls backed by structured engine events.
- Isolated app-owned Wine prefix and runtime overlay; no adoption of existing
  bottles or vendor accounts.
- Source-built Steam and SocialClub helper delegates with bounded Windows argv
  quoting and inherited handles.
- Repeatable Apple Silicon app packaging with checksum-pinned standalone Python,
  complete upstream runtime license inventory, unsigned CI artifact upload, and
  optional local Developer ID signing/notarization.
- Explicit external Apple dependency licensing and read-only source import
  boundaries, with clean-install and gameplay release gates.

This release does not certify new-machine installation or gameplay. Existing M4
playability is evidence about a separate, pre-existing environment only.
